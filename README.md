The Wind Waker HD — 4:3 Graphics Pack (Experimental)

Maintainer: Hussein Mohammad Hussein Abdelaziz  
Development note: AI assistance was used to investigate bugs and improve code readability for future development.

A community-style Cemu graphics pack experimenting with 4:3 rendering in The Legend of Zelda: The Wind Waker HD. Intended for Cemu Android but not independently validated across builds.

Installation
Back up your existing graphics packs.
Copy this folder into Cemu’s graphicPacks directory.
Disable other Wind Waker HD resolution/aspect packs to avoid conflicts.
Enable 4:3 Fullscreen + HUD Test and select a 4:3 preset.
Restart the game.

Presets
960 × 720
1280 × 960
1440 × 1080

Current status
A previous fullscreen variant was shown rendering 4:3 on the user's handheld, with the HUD cropped.
This variant attempts to improve HUD placement by using separate 16:9 HUD values. The HUD change has not been confirmed in-game.
The exact roles of the two HUD patch addresses are not independently verified.
Shadow/lighting behavior may vary with device and build.

Files
rules.txt: graphics pack metadata, presets, and render-target overrides.
patches.txt: region-specific executable patches.

Troubleshooting
If the HUD is still cropped, shadows break, or the picture stretches, disable this pack and restore your previous working version. Report your Cemu version, game region, chosen preset, and a screenshot when filing issues.
